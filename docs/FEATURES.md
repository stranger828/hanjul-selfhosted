# 기능과 동작 방식

## 구현된 기능

- 제목 없는 본문 입력, 첫 의미 있는 줄을 목록 제목으로 사용. `⌘/Ctrl+Enter`로 빠르게 다음 메모, `⌘/Ctrl+K` 검색, `⌘/Ctrl+S` 즉시 저장.
- 제목·본문·첨부가 없는 메모(공백이나 빈 목록·체크리스트만 있는 경우 포함)는 저장하지 않습니다. 기존 메모를 전부 비우면 마지막 저장 내용이 유지됩니다.
- 입력 650ms 후 자동 저장, 편집 도구 오른쪽 **저장** 버튼으로 대기 없이 즉시 저장. 서버 응답 이후에만 ‘저장됨’. 전송 중 변경도 후속 저장. 15초 응답 제한, 저장 실패·수정 충돌 표시.
- 열어 둔 메모는 화면이 보일 때 5초마다, 앱으로 돌아올 때 즉시 최신 버전을 확인합니다. 미수정 상태는 자동 갱신하고 작성·저장·한글 조합 중에는 덮어쓰지 않습니다. 충돌 초안은 별도 메모로 저장할 수 있습니다. 실시간 공동 편집·자동 병합은 지원하지 않습니다.
- 입력 때마다 기기 로컬 초안 보관. 새로고침 후 목록의 복구 배너에서 복구·재저장. 저장 공간 부족도 표시. 초안은 로그인한 동일 데이터 저장소에 연결됩니다.
- 본문 안에서 링크를 열고 첨부 이미지를 볼 수 있는 가벼운 편집기 + 목록·체크리스트·링크·첨부 버튼. 스크린샷을 본문에 붙여넣으면 커서 위치에 이미지로 저장합니다. 편집 중 이미지를 누르면 네 모서리에 조절점이 나타납니다. 모서리를 드래그하면 사진 비율을 유지하며 메모 너비의 20~100%로 크기를 조절하고, 마우스를 놓으면 자동 저장합니다. Escape로 드래그를 취소할 수 있으며 조절점의 방향키 또는 **크기 입력**으로도 조절할 수 있습니다. 기본 크기 복원은 **크기 입력 → 기본 크기**에서 가능합니다. 원본은 크기 조절 창 또는 읽기 화면에서 엽니다. 링크는 앱 내부 입력창으로 추가합니다. 읽기 화면에서는 체크리스트를 클릭할 수 있습니다. 원본 본문은 UTF-8 Markdown으로 보존합니다.
- 선택한 글자에 **굵게**, **취소선**, **글자 크기(12~40px, 기본 17px)**를 적용할 수 있습니다. 선택 없이 서식을 켜면 이어서 입력하는 글자에 적용됩니다. 굵게는 `⌘/Ctrl+B`, 글자 크기는 `⌘/Ctrl+＋`와 `⌘/Ctrl+－`로 바꿉니다(`⌘/Ctrl+=`도 확대). 본문을 편집할 때만 적용하며, 선택 없이 크기를 바꾸면 이어서 입력할 글자에 적용합니다. **표 ▾** 버튼의 그리드에서 행·열을 고르면 바로 삽입됩니다(10열 × 8행). 방향키와 Enter로도 선택하며, **행·열 직접 입력**을 펼치면 최대 20행·10열을 넣을 수 있습니다. `Tab` / `Shift+Tab`으로 셀을 이동하며 마지막 셀에서 `Tab`을 누르면 표 아래로 이동합니다. 서식과 표는 자동 저장·읽기·ZIP 내보내기/가져오기에 보존됩니다.
- 표 바깥 테두리에 마우스를 올리면 화살표 커서로 바뀌고, 클릭하면 초록 테두리와 모서리와 각 변 중앙의 크기 조절점이 나타납니다. 모서리를 드래그해 너비·높이를 바꾸고, 위·아래 중앙 조절점으로 높이만 바꿀 수 있습니다. 내용이 잘리지 않도록 최소 크기는 유지합니다. Delete/Backspace는 선택한 표 전체를 삭제하며, `⌘/Ctrl+Z`로 되돌릴 수 있습니다. 표 안에서 기본 드래그는 셀 범위를 선택하고, `⌘/Ctrl`을 누른 드래그는 글자를 선택합니다. 선택한 셀은 `⌘/Ctrl+C`로 복사하고 대상 셀에서 `⌘/Ctrl+V`로 붙여넣습니다. 셀 안의 이미지도 클릭 후 Delete/Backspace로 삭제하며 되돌릴 수 있습니다. 선택한 셀은 Shift+클릭·Shift+방향키로 범위를 확장하고 Delete로 내용만 지울 수 있습니다. 셀을 클릭하거나 Enter를 누르면 글자를 편집합니다. 크기는 자동 저장되며 읽기 화면과 내보내기에도 보존됩니다.
- 엑셀·스프레드시트에서 셀 범위를 복사해 붙여넣으면 행·열과 셀 안의 줄바꿈을 유지합니다. HTML 표의 병합 셀과 기본 글자 서식을 지원하며, 탭으로 구분된 텍스트도 표로 변환합니다(한 번에 최대 200행·50열). 일반 표의 셀 안에 붙이면 그 셀부터 채우고 필요한 행·열을 늘립니다. 병합된 표는 기존 표 밖에 붙여넣습니다.
- 체크리스트는 편집 화면에서도 클릭하거나 Space 키로 완료를 전환할 수 있습니다. Enter는 다음 항목을 만들고, 빈 항목에서 Enter 또는 항목 맨 앞에서 Backspace를 누르면 일반 문장으로 돌아옵니다. 기존 `- [ ]` / `- [x]` 메모도 다시 열면 체크박스로 표시됩니다.
- 사진이 있는 메모는 목록 오른쪽에 첫 본문 이미지가 썸네일로 표시됩니다. 이미지 문법과 저장 경로는 제목·본문 미리보기에서 숨기고, 글 없이 사진만 있는 메모는 ‘사진 메모’로 표시합니다.
- 한국어 부분 문자열, 영문 대소문자 구분 없는 검색. 공백으로 나눈 모든 단어를 포함하는 AND 검색. 제목과 본문에 나눠 포함되어도 일치.
- 최근 수정순 / 오래된 수정순, 사용자 기기의 시간대, 수정일 범위·정확한 태그 필터, 결과 본문 발췌·강조, 40건씩 더 보기. 목록 복귀 시 검색과 로드한 목록·스크롤 복원.
- 목록의 메모를 길게 누르거나 **선택**을 누르면 체크박스가 나타납니다. 여러 메모를 선택해 한 번에 휴지통으로 이동하고, 휴지통에서 복구할 수 있습니다. **현재 목록 전체 선택**은 불러온 목록에 적용되며 검색·폴더를 바꾸면 선택을 해제합니다.
- 선택적인 중요 표시·복수 태그·보관함·휴지통 복구. ‘모든 메모’는 보관함 포함, 휴지통 제외. 휴지통에서는 별도 검색.
- 메모 ID에 연결한 첨부파일. 파일마다 UUID, 같은 이름 허용, 파일당 20MB. 이미지 PNG/JPEG/GIF/WebP는 읽기 화면에서 표시하고 다른 파일은 다운로드.
- 전체 ZIP 내보내기 및 v1 ZIP 가져오기 미리보기. 동일 ID는 **항상 건너뛰며 기존 내용을 덮어쓰지 않습니다**. 다른 ID의 동일 내용은 별도 메모로 처리합니다.
- 인증된 API, 읽기 전용/쓰기 토큰, 토큰 개별 폐기. 모든 메모·첨부 경로에 인증. 쿠키 세션은 HttpOnly/SameSite=Strict와 CSRF 검증 적용.

## 로그인과 패스키

- 비밀번호 로그인 시 **이 브라우저에서 30일 유지**를 선택할 수 있습니다. 해제하면 세션 쿠키와 서버 최대 12시간을 적용합니다. 30일은 로그인 시점부터 계산하며 접속할 때마다 연장하지 않습니다.
- 로그인 후 **설정 → 패스키·로그인된 기기 → 패스키 등록**을 누르세요. 이후 로그인·본인 확인에 지문 또는 기기 잠금을 사용할 수 있습니다. 컴퓨터에서도 지원되는 패스키를 사용하거나 비밀번호로 로그인합니다.
- 내보내기·가져오기, 비밀번호 변경, 토큰 발급/폐기, 패스키 등록/삭제, 기기 로그아웃은 최근 5분 이내 본인 확인이 필요합니다. 인증이 오래되면 작업 도중 패스키 또는 비밀번호 확인 창이 열립니다. 메모 작성·검색에는 이 확인을 요구하지 않습니다.
- 등록한 패스키와 로그인된 브라우저를 설정에서 개별 삭제/해제할 수 있습니다. 패스키 삭제는 그 패스키로 로그인한 세션도 해제합니다. 생체 정보와 개인 키는 서버로 보내거나 저장하지 않습니다. 기기 이름은 표시용이며 기기 추정만으로 로그인하지 않습니다.
- 패스키는 앱 주소에 연결됩니다. 로컬에서는 **localhost** 주소를 사용하세요. 별도 시험 사이트에 등록한 패스키는 본 앱에서 다시 등록해야 합니다. 휴대폰에서 본 앱을 쓰려면 고정 HTTPS 주소와 영속 저장소를 갖춘 배포가 필요하며, 이 변경만으로 휴대폰용 본 앱이 배포되지는 않습니다.
- 기존 로그인은 원래 만료일을 유지합니다. 다음 로그인부터 30일 설정이 적용됩니다.

자세한 보안·복원 규칙은 [운영 안내](OPERATIONS.md#로그인과-패스키-운영)를 참고하세요.

## 저장 구조와 충돌

Flask + Waitress, SQLite WAL, 외부 프런트엔드 빌드나 클라우드 서비스 없는 구성입니다. 원본은 `.data/memo.sqlite3`입니다. 메모, 태그, 수정 버전, 인증 설정과 **첨부 BLOB**이 같은 DB에 있습니다. BLOB은 SQLite에 파일 바이트를 직접 저장하는 방식입니다. 첨부 등록과 본문 링크·버전 갱신을 하나의 트랜잭션에서 처리하므로 파일만 저장되거나 링크만 남는 상태를 막습니다.

수정·삭제·첨부 요청은 조회한 `version`을 제출합니다. DB에서 `WHERE id=? AND version=?`로 원자적으로 갱신하고 버전을 증가시킵니다. 다른 곳에서 이미 수정했다면 HTTP 409와 최신 내용을 반환합니다. UI는 초안을 유지하고 서버 내용 확인 또는 **첨부까지 복제한 새 메모 저장**을 제공합니다. 조용한 마지막 쓰기 덮어쓰기는 하지 않습니다. 생성 시 클라이언트 UUID를 사용하므로 응답 유실 후 재시도도 중복 ID를 감지합니다.

## 검색 설계와 한계

SQLite FTS5 **trigram**은 연속 3글자 조각을 색인해 한국어 중간 부분도 찾습니다. 3글자 이상의 검색어로 후보를 좁히고, 모든 검색어를 서버에서 `instr(lower(...))`로 최종 확인합니다. 1~2글자만 입력하면 서버의 범위 내 메모를 스캔합니다. 한글은 NFC로 정규화하며 `%`, `_`, 따옴표도 사용자 문자열로 취급합니다. SQL은 매개변수 바인딩, FTS 입력은 따옴표 이스케이프를 적용합니다.

목록에는 전체 본문이 내려가지 않고 제목·최대 240자 발췌·메타데이터만 내려갑니다. 페이지당 최대 100개, UI 기본 40개입니다. 기본 정렬은 검색 점수가 아닌 **수정 시각 내림차순, 동일 시각은 ID 내림차순**입니다. 발췌는 본문에서 가장 먼저 일치한 위치 주변이며 서로 멀리 있는 모든 단어가 한 발췌에 표시되지는 않을 수 있습니다.

- 형태소 분석, 초성 검색, 오타 보정, 유의어, 의미 검색은 없습니다. ‘회의’는 ‘회의록’에 일치하지만 ‘회 의’는 두 단어의 AND 조건입니다. 검색어의 따옴표는 구문 연산자가 아닙니다.
- 1~2글자 또는 매우 흔한 단어는 본문 총량에 비례해 느려집니다. 인덱스도 저장 공간을 사용합니다. 일반 페이지네이션은 offset 방식으로, 여러 기기가 수정하는 중 페이지를 넘기면 위치가 달라질 수 있습니다. 읽기 스냅샷을 장기 고정하지 않습니다.
- 초기 버전은 개인 1명용, 단일 서버·단일 로컬 디스크 기준입니다. 대량 첨부와 동시 쓰기가 커지면 PostgreSQL/검색 전용 인덱스 및 객체 저장소로 이관할 수 있도록 API 경계가 분리되어 있습니다.
- 근거: [SQLite FTS5 trigram 공식 문서](https://www.sqlite.org/fts5.html#the_trigram_tokenizer), [Flask 파일 업로드 공식 문서](https://flask.palletsprojects.com/en/stable/patterns/fileuploads/).


## 폴더로 묶기

- 모바일에서는 상단 **☰**를 누르면 왼쪽에서 폴더 메뉴가 열립니다. 폴더 선택, 바깥 영역 터치, 닫기 버튼 또는 Escape로 닫습니다.
- ‘모든 메모’ 아래의 **폴더 ＋**로 폴더를 만듭니다. 이름 오른쪽 숫자는 휴지통을 제외한 메모 개수입니다.
- 폴더 이름을 누르면 해당 폴더의 메모만 보입니다. 연필 버튼으로 이름을 바꿀 수 있습니다.
- 메모 아래의 **폴더** 선택으로 분류하거나 ‘폴더 없음’으로 옮깁니다. 선택한 폴더에서 새 메모를 만들면 바로 그 폴더에 저장됩니다.
- 기존 메모는 그대로 ‘폴더 없음’에 있습니다. 폴더 정보도 SQLite 백업과 ZIP 내보내기·가져오기에 포함됩니다.


## 남은 범위

완전한 오프라인 동기화, 자동 병합, 변경 이력, 다중 사용자, 첨부 개별 삭제·휴지통 영구 삭제는 없습니다. 로컬 초안은 브라우저 저장 공간 삭제·비공개 모드 종료·기기 분실까지 보장하지 않으며 앱 로그아웃 후에도 해당 기기의 초안은 남습니다. 공유 기기에서는 복구 배너의 초안을 삭제하세요. 비밀번호 변경은 API 토큰을 자동 폐기하지 않으므로 필요 시 각각 폐기하세요.

클립보드에 표가 있으면 표를 우선 삽입하고, 이미지 파일만 있으면 첨부로 저장하며, 나머지 붙여넣기는 일반 텍스트로 처리합니다. 복사한 표에서는 셀 내용·병합·기본 글자 서식만 가져옵니다. 외부 이미지, 스크립트, 임의의 웹페이지 스타일은 가져오지 않습니다. 키보드로 직접 입력한 URL은 메모를 다시 열 때 링크로 표시하며, 링크 버튼과 URL 붙여넣기는 즉시 링크로 표시합니다. 링크 표시 글자는 링크와 함께 하나의 단위로 선택·삭제하며, 변경은 삭제 후 다시 삽입합니다.

Markdown 읽기는 일반 줄·목록·체크리스트·링크·첨부를 지원하는 경량 보기입니다. 서식과 표는 제한된 HTML 태그(`strong`, `s`, 글자 크기용 `span data-size`, `table`)로 Markdown 본문에 함께 저장합니다. 일반 HTML이나 스크립트는 실행하지 않습니다. 수식·파이프 표·복잡한 중첩 문법을 렌더링하는 전체 Markdown 편집기는 아닙니다. 외부 이미지 주소는 자동으로 로드하지 않습니다. 첨부 실패 시 파일을 다시 선택하거나 이미지를 다시 붙여넣어 주세요. 조절한 크기는 Markdown 이미지 제목 속성(`"width=50%"`)으로 함께 저장되며 ZIP 내보내기·가져오기에도 보존됩니다.

ZIP 업로드와 압축 해제 총량은 각각 256MB, 메모 2만 개, 파일 5만 개까지입니다. 큰 데이터는 운영 DB 백업으로 보존하세요. 가져오기는 미리보기와 실행 시 파일을 재검증하고 한 트랜잭션으로 처리합니다. 만료된 미리보기는 다음 미리보기 시 정리됩니다.

네이버 전용 가져오기는 원본 샘플을 받은 뒤 형식 어댑터로 추가할 예정입니다. AI 의미 검색·추천과 MCP 서버는 후속 범위이며 **ChatGPT 연결이 완료된 상태가 아닙니다**. 브라우저가 실험적 WebMCP를 지원하는 경우 검색 도구 등록을 시도하지만 일반 사용·검색은 이 기능 없이 동작합니다.
