# 한줄을 만든 목적과 장점

## 만들고자 한 것

한줄은 작업 중 떠오른 생각과 자료를 빠르게 남기고, 나중에 기억나는 단어로 다시 찾기 위한 개인 메모 도구입니다. 메모를 시작하기 전에 제목·폴더·분류부터 결정하는 부담을 줄이고, 기록 자체에 집중하는 것을 목표로 합니다.

짧은 생각 한 줄로 시작해 필요하면 링크, 스크린샷, 체크리스트, 표를 덧붙입니다. 기록을 정리하는 시점은 사용자가 선택합니다. 제목 없이 작성해도 첫 의미 있는 줄이 목록에 보여 다시 찾을 수 있습니다.

## 일할 때의 편의성

| 작업 상황 | 한줄에서 하는 일 | 편리한 이유 |
| --- | --- | --- |
| 다른 일을 하다가 생각이 떠오를 때 | 새 메모를 열고 바로 입력 | 제목이나 분류를 먼저 정하지 않아도 됩니다. |
| 회의·자료 조사 내용을 남길 때 | 글과 링크, 스크린샷을 한 메모에 기록 | 관련 자료를 함께 다시 볼 수 있습니다. |
| 할 일을 간단히 적을 때 | 체크리스트 작성·완료 전환 | 짧은 기록을 위해 별도 작업 관리 도구를 열 필요가 줄어듭니다. |
| 숫자나 항목을 비교할 때 | 표 입력·스프레드시트 셀 붙여넣기 | 메모 안에서 간단한 비교를 이어갈 수 있습니다. |
| 예전에 적은 내용을 찾을 때 | 한국어 일부 단어나 여러 단어로 검색 | 정확한 제목이나 저장한 폴더를 기억하지 않아도 됩니다. |
| 컴퓨터와 휴대폰을 오갈 때 | 같은 서버 주소에 접속 | 각 기기에 메모 파일을 수동으로 복사할 필요가 없습니다. |

입력을 멈추면 자동 저장하고, 서버가 응답한 뒤 저장 상태를 표시합니다. `⌘/Ctrl+Enter`는 빠르게 다음 메모로, `⌘/Ctrl+K`는 검색으로, `⌘/Ctrl+S`는 즉시 저장으로 이어집니다.

## 기록을 잃지 않도록 돕는 설계

기기 로컬 초안, 저장 실패 표시, 수정 버전 검사를 제공합니다. 두 기기에서 같은 메모를 수정하면 충돌을 표시하고 초안을 별도 메모로 보존할 수 있습니다. 작성 중인 내용을 다른 기기의 새 내용으로 조용히 덮어쓰지 않습니다. 미수정 상태에서는 서버의 최신 내용을 주기적으로 확인합니다.

이 기능들은 손실 위험을 줄이기 위한 장치입니다. 브라우저 데이터 삭제나 기기 분실까지 보장하지 않으므로 서버 백업을 함께 운영해야 합니다.

## 내 저장소를 선택하는 자유

로컬 PC, 집의 NAS, 별도 Linux 서버, AWS EC2 중 자신의 환경에 맞는 곳에 설치합니다. 같은 앱을 쓰면서 저장 위치와 도메인, 백업 위치를 직접 결정할 수 있습니다. 앱 사용에 외부 클라우드 API나 AI 서비스 구독은 필요하지 않습니다. 호스팅·도메인·백업 비용은 선택한 환경에 따라 발생합니다.

메모와 첨부를 SQLite DB 하나로 함께 백업할 수 있고, 앱 밖에서 보관할 때는 Markdown과 첨부파일이 담긴 ZIP으로 내보냅니다. 특정 호스팅 서비스에 종속되지 않고 서버를 옮길 수 있도록 데이터 이동 경로를 둡니다.

## 잘 맞는 사용 방식

- 작업 중 짧은 기록과 개인 자료를 한곳에 모으고 싶은 사람.
- 한국어 메모를 제목보다 내용으로 찾는 사람.
- NAS나 개인 서버를 운영하며 메모의 저장 위치를 직접 관리하고 싶은 사람.
- 많은 분류 규칙보다 가벼운 입력과 검색을 선호하는 사람.

현재 한줄은 한 사람의 기록을 위한 도구입니다. 팀 공동 편집, 대규모 문서 관리, 완전한 오프라인 작업이 필요하면 해당 기능을 갖춘 도구가 더 적합할 수 있습니다. 한줄의 방향은 **적기 쉽게 만들고, 찾기 쉽게 남기며, 데이터를 내가 보관하는 것**입니다.
